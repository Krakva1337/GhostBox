# GhostBox icons

Each named preset is available as PNG, SVG and ICO. The set follows the built-in
color families; `classic` keeps the original GhostBox mark. The Flutter app uses
the PNG previews, Android and iOS bundle launcher variants, and Windows uses
the ICO files for its window icon.

The `custom` icon is drawn at runtime from the two colors selected in Appearance
and is saved independently from the app theme.
